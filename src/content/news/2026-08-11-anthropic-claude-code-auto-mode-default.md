summary: >-
  Anthropic is making "auto mode" the default in Claude Code for Pro, Max,
  and Team accounts starting August 14, letting the coding agent act without
  asking for approval at each step unless an action is judged irreversible,
  destructive, or reaching outside the user's environment. Anthropic said an
  internal study of 1,053 paid users found auto mode caught 89% of harmful
  actions versus 13.6% for manual review, attributing the gap to reflexive
  approval — users approved 97% of permission prompts. New guardrails
  include prompt-injection screening and hard-deny rules for actions like
  data exfiltration.
implications: >-
  For any business using AI coding tools, the assumption that a human checks
  every step before an agent acts is quietly becoming false — one of the
  largest AI labs is saying manual review performs worse than the automated
  check replacing it. It's worth understanding what an agent can do
  unsupervised before adopting one, not after.
