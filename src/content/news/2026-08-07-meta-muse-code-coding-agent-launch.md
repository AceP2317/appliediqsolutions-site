summary: >-
  Meta released Muse Code, a terminal coding agent for macOS and Linux
  powered by its new Muse Spark 1.2 model, putting it in direct competition
  with Claude Code, Codex, and Cursor. Muse Code plans changes, writes code,
  and validates results across large repositories, coordinating persistent
  background subagents that stay active for an entire session rather than
  spinning up per task. Its runtime logs every model call, tool run,
  approval, and edit so a session can resume exactly where it left off after
  a crash. Muse Spark 1.2 was co-trained alongside the agent specifically to
  perform well inside it, with heavier training on long-horizon,
  whole-repository coding tasks.
implications: >-
  The market for AI coding agents just gained a well-funded entrant with its
  own model tuned specifically for the harness around it, rather than a
  general-purpose model retrofitted for coding. For any business already
  routing engineering work through one of these tools, expect the
  competition among them to keep pushing capability and price — worth
  periodically re-checking whether the tool you picked six months ago is
  still the best fit.
