summary: >-
  At the Future of Memory and Storage conference on Aug. 4, Samsung unveiled
  zHBM, which stacks memory chips directly on top of an AI processor instead
  of beside it, promising up to roughly eight times today's HBM5 performance
  along with higher density and lower power and heat, according to a Samsung
  press release. At the same event, SK Hynix and Sandisk published the first
  open-standard specification for a rival approach called High Bandwidth
  Flash, which adds a layer of NAND-based capacity between HBM and SSDs so
  AI models too large for HBM alone can stay closer to the processor.
  Samsung separately introduced a denser NAND storage chip, V10 BV-NAND.
implications: >-
  Memory bandwidth, not raw chip speed, has become the bottleneck limiting
  how fast data centers can train and run AI models, and this follows an
  Aug. 6 report on that same shortage. These are competing, incompatible
  bets by the top memory makers rather than a settled fix, so which approach
  wins affects how fast AI hardware costs come down and how quickly the
  current memory shortage eases.
